# XMUOJ VS Code 插件

在 VS Code 中完成 XMUOJ 的找题、读题、写代码、本地测试和提交。

## 主要功能

- 登录 XMUOJ，搜索题目与实验；支持本地工作区即时过滤
- 启动时自动扫描本地题目目录，已下载的题库与实验无需重新搜索
- 首次安装/升级自动整理本地数据：迁移旧目录、重建索引、修复时间胶囊索引、同步题库标记
- 打开题目，自动创建或恢复本地代码工作区；同题在公共题库/实验中共用一个目录
- 下载测试数据并在本地运行，支持 C、C++、Java、Python3
- 提交评测，自动检查题目语言限制并轮询判题结果
- 保存提交历史，支持查看、筛选、清理
- 刷题台：全站排名、已做/未做分布、最近提交与关注的人
- 题库竞速：只在「我的题库」的题库实验中开放实时同题竞速，实验/考试默认禁用，避免作弊
- 代码时间胶囊：手动录制某道题的完整编码与调试过程，本地回放、拖拽定位，可导出胶囊文件或 WebM 视频
- 题面、代码、结果支持分栏布局；重启 VS Code 后自动恢复上次布局
- 实验（Contest）状态感知：自动提示进行中 / 准备中 / 已结束
- 离线容错：断网时保留登录凭证与本地题库，状态栏一键重试
- 活动栏、工具栏与题目状态使用统一的图标语言，并跟随明暗主题

## 使用流程

1. 执行 `快速开始`，选择本地工作区目录并按提示登录
2. 从同一个入口搜索题目、打开我的实验或公共题库
3. 点击 `打开代码` 创建或恢复本地工作区
4. 需要换语言时点击 `切换代码语言`
5. 写完后运行 `运行本地测试`
6. 通过后执行 `提交评测`
7. 在 `结果报表` 中查看本地和在线结果

侧边栏「刷题工作台」分为四组：

- **最近在做**：最近打开的 10 道题，可一键继续
- **我的实验**：已加载的正式实验（可能是比赛或考试），展开即题目列表；不提供竞速
- **我的题库**：教材配套的题库实验，展开即题目列表；右键题库可打开「题库竞速」
- **公共题库**：搜索入口、刷题台与刷题队列，只提供刷题

右键实验或题库可以刷新、批量初始化题目目录或从列表移除。移除会记住隐藏状态：即使本地仍保留该实验的题目目录，刷新后也不会重新出现；再次通过 `搜索实验` / `搜索题库` 加载同一实验即可恢复。

「我的实验」和「我的题库」在站点后台是同一类数据（Contest）。插件以服务端返回的 `is_question_bank` / `is_exam` 为准，并把标记缓存在本地；早期版本只保存了实验标题，启动后会通过公开的 `/api/plugin/contests` 自动补齐。标题以 `[教材]` / `【教材】` 开头的隐藏 OI 实验也会归入题库，这只是服务端没有标记时的兜底；考试实验一律不开放竞速。

## 首次安装与升级时的数据整理

升级到当前版本后第一次启动，插件会执行一次本地数据整理；之后启动只做只读扫盘：

1. **题目目录**：把旧 `contest-*` / `problemsets` 布局迁入 `problems/`，保留 v1 元数据备份；无元数据、正在编辑或非空目录不会被删除。
2. **题目索引**：重建 `.xmuoj/index.json`，让「最近在做」「我的实验」「我的题库」恢复上次的题目。
3. **时间胶囊**：以 `.xmuojcapsule` 文件为准重建 `index.json`，为旧胶囊补齐题目键与「第几次尝试」序号；只改写索引，不修改胶囊文件，也不会上传。
4. **题库标记**：同步每个已加载实验的 `is_question_bank` / `is_exam`，把教材题库从「我的实验」移动到「我的题库」。离线时会保留原标记，联网后自动重试。

整理失败不会删除任何用户文件；时间胶囊索引失败时保留迁移版本号，下次启动自动重试。也可以随时执行 `整理本地数据` 手动重跑上述步骤。

登录、选择工作区、迁移/重建索引、检查更新等操作在视图标题栏的账户菜单与命令面板中。

## 公共题库刷题台

执行 `打开公共题库` 打开编辑器内的刷题台。顶部固定显示头像、用户名、全站排名、AC/提交/通过率与目录同步状态；下方分四个标签页：

- **概览**：已 AC / 尝试过 / 未做 / 全站排名四张卡片，按难度统计的进度条，最近提交、我的实验战绩和关注的人。竞速入口不在这里，见下方「题库竞速」。
- **题库**：完整题目目录（自动分页拉取并缓存 30 分钟），可按状态、难度、标签、关键词筛选，按题号/难度/通过率/提交数排序；工具栏下方会写明当前排序方向（通过率与提交数均为从高到低）。每道题显示站点状态与本地进度的合并结果；本地 AC 但站点未记录时标注「本地」，不会伪造站点状态。每行的「排行」打开本题榜单，可在三种排序间切换：**首次 AC**（历史首杀顺序）、**最快通过**（该用户首次提交到首次 AC 的用时，跨年份可比）、**AC 次数**（反复练习次数），并附最近提交动态。所有历史时间都带年份；本题提交记录超过约 2500 条时只统计最近窗口，并明确提示「用时为窗口内近似值」。
- **排行**：ACM / OI 切换，Top 50 榜单与自己的精确名次、并列区间、百分位。榜单接口没有 `my_rank`，插件按每页 2000 人拉取并建立索引，名次与站点顺序一致；没有 AC 时明确显示「未上榜」。
- **关注**：关注任意站点用户，查看 AC/提交/总分/最近提交/实验战绩；点击用户名打开资料抽屉。关注关系只保存在本地（`xmuoj.followedUsers`），不依赖站点后端。

回放不放在刷题台里：每道题的录制都在它自己的编辑器区域回放，见下一节。

刷题队列顺序现在稳定：打开题目或查看题面不会改变队列顺序，只有「优先下一题」会显式置顶；队列游标持久化，重启后继续从上次位置往下刷。题目目录、个人进度与排名都有缓存，断网时继续显示上次数据并标注来源。

## 题库竞速

竞速只在**题库**中提供，不对公共题库开放。实验有时是比赛或考试，若允许实时看到对手提交就会破坏公平性；只有题库这类不计成绩的练习集合才适合竞速。

1. 在侧边栏展开「我的题库」，或执行 `搜索题库`。
2. 右键题库选择 `题库竞速`，打开该题库的竞速面板。
3. 输入同班同学的用户名，页面会列出对方在这个题库里的提交与 AC 情况。
4. 选择题目、填写对手并选择时限，点击 `开始竞速`：
   - 插件生成 `XMJ1.` 开头的实时竞速口令并复制到剪贴板，15 秒后正式开始。
   - 对手在同一题库的竞速面板粘贴口令加入。房主填写的对手用户名用于双方互相轮询提交，建议在开始前填写。
   - 插件每 10 秒轮询双方在该题上的实验提交，以服务端提交时间判定先 AC 者胜。
5. **同一时间只允许一场竞速**：当前竞速结束前不能再次发起或加入，切换其他题库也会被拒绝。需要换题或重新开始时，先点击 `结束竞速`。
6. 每人最多 6 人参与；截止后 120 秒宽限补判；双方都未 AC 时显示「无人完成」，不按提交次数判胜。

影子竞速已下线：新竞速只提供实时模式，旧版影子口令会被拒绝；升级时本地遗留的影子记录会被清理，实时竞速历史保留。

竞速记录按题库分别保存在本地（`xmuoj.contestRaces.v1`），口令只含题库、题目、参与者和时间，不含任何凭证。实验内提交通过 `/api/contest_submissions` 读取，因为公开的 `/api/submissions` 会排除所有实验提交；若站点因「比赛进行中」拒绝读取，面板会明确提示并暂停轮询，不会误判胜负。

考试实验（`is_exam`）即使带有题库标记，也会被强制禁用竞速。

## 代码时间胶囊

时间胶囊把一道题从第一行代码到 AC（或放弃）的完整过程录下来：每一次编辑、光标位置、本地运行、提交和判题结果都有时间戳。它适合复盘“当时为什么这么改”，也可以作为教学演示素材。

### 录制

打开某道题的代码文件后，会同时出现三个可见入口：

- 编辑器第一行的 CodeLens：`开始录制时间胶囊`；录制中变成 `暂停录制时间胶囊` / `停止并保存时间胶囊`，暂停后变成 `继续录制时间胶囊`。
- 底部状态栏：空闲时显示 `录制时间胶囊`，点击即可开始；录制中显示 `录制中 00:12:34`，旁边还有独立的 `暂停录制` 和 `停止并保存` 按钮。
- 编辑器标题栏的录制图标，或右键菜单中的同名命令。

开始录制时会弹出通知，明确说明已开始，并直接提供 `暂停` / `停止并保存` 两个操作。暂停期间不计入时长，状态栏会显示 `已暂停 00:12:34`。

停止后，插件会**自动打开本题的回放标签页**，顶部出现一条“本次录制已保存”的摘要：第几次尝试、时长、编辑/运行/提交次数、最终结果，以及 `播放全过程`、`对比上一次`、`导出视频`、`导出胶囊` 按钮。摘要可以关闭；关闭后仍可在回放页顶部点击 `录制摘要` 重新打开当前尝试的摘要。

录制内容仅限**当前这道题的当前代码文件**：文本编辑、光标与选区（可关闭）、保存、语言切换、模板/格式化等程序化修改，以及本地运行和在线提交的判定结果。题面、测试数据、终端输出和其他文件都不会被录制。

- 每 60 秒或每 300 个事件写入一个完整文本检查点，回放定位时从最近的检查点恢复，长录制也不会卡。
- 录制过程边录边写 NDJSON；若 VS Code 异常退出，下次激活会提示恢复未完成的时间胶囊。
- 达到大小上限（默认 50MB）或事件上限（50 万）时自动停止并保存已录内容。

### 回放

回放按**题目**组织，不再占用刷题台的标签页。打开某道题的代码文件后，有三种入口：

- 编辑器标题栏的 `回放本题` 按钮（这道题已有录制时出现；没有录制时显示 `开始录制`）。
- 编辑器内 CodeLens 的 `回放本题`（默认开启，可在 `xmuoj.editor.shortcuts` 中调整）。
- 命令面板执行 `回放本题`；也可以用 `时间胶囊回放` 从全部胶囊中选择。

同一个题目的多次录制会聚合成一个回放标签页，顶部是「尝试」列表：第几次、结果、录制时间、时长，以及编辑/运行/提交次数。点击任意一次即可切换，不会为每次尝试新开标签页；`对比上一次` 用 VS Code 原生 diff 打开两次尝试的最终代码，适合复盘“这次改对了什么”。没有录制时，回放入口会直接引导开始第一次录制或导入胶囊。

回放面板包含：

- 只读代码视图：行号、当前行高亮、光标与选区，自动滚动跟随。
- 时间轴：事件密度热力图、运行/提交/AC/失败标记，可拖拽到任意时刻。
- 控制条：播放/暂停、上一/下一编辑、上一/下一标记、0.5–16 倍速、跳过停顿（把大于 3 秒的空白压缩到 1 秒）。
- 打开最终代码、另存代码、导出胶囊、导出 WebM。
- 快捷键：空格播放/暂停，方向键前后跳 5/30 秒，Home/End 到开头/结尾。

录过胶囊的题目在侧边栏题目树和刷题台题库行会标注「有回放」。删除当前查看的录制可直接点回放页顶部的 `删除本次`（摘要里也有同名按钮），需要二次确认；要删除其他历史录制，先在「尝试」列表切换到那一次，或执行 `删除时间胶囊` 从全部胶囊中选择。

### 新建代码模板

新建源码时使用各语言的最小可运行模板。C++ 模板**不使用** `#include <bits/stdc++.h>`，而是：

```cpp
#include <iostream>
#include <algorithm>
#include <cstring>
using namespace std;
```

这是因为 macOS 的 libc++ 环境没有 libstdc++ 的万能头。已有文件如果还包含万能头，可打开该 C++ 文件后执行 `替换 C++ 万能头文件`：插件只把单独成行的 `#include <bits/stdc++.h>` 换成上面三个头，其余代码不动，保存后生效。

### 存储、导出与隐私

- 默认存储在 VS Code 的全局存储目录 `timecapsules/` 下，纯本地，不上传、不联网。
- `导出时间胶囊` 生成单个 `.xmuojcapsule` 文件（gzip 压缩的 NDJSON）；换机器或换 profile 后用 `导入时间胶囊` 恢复。
- 回放面板可把过程渲染成 **WebM** 视频：画布逐帧重放，按 1×/2×/4× 速度推进，默认 1280×720、30fps，可配置。超过 10 分钟的素材会先提示，超过 30 分钟或 20 万事件拒绝导出；取消导出会删除半成品。
- `删除时间胶囊` 需要二次确认，删除后不可恢复。

## 常用配置

| 配置项 | 说明 |
|--------|------|
| `xmuoj.localWorkspaceRoot` | 本地工作区根目录 |
| `xmuoj.enableSideMode` | 是否启用分栏布局（默认开启） |
| `xmuoj.colorizeProblems` | 是否在题目树中显示状态颜色和图标 |
| `xmuoj.editor.shortcuts` | 编辑器顶部显示哪些快捷操作（CodeLens） |
| `xmuoj.problemset.catalogTtlMinutes` | 刷题台题目目录缓存有效期，默认 30 分钟 |
| `xmuoj.problemset.pageSize` | 刷题台题库每页题目数，默认 50（10–200） |
| `xmuoj.race.pollIntervalSeconds` | 题库竞速轮询间隔，默认 10 秒（5–120） |
| `xmuoj.timeCapsule.maxSizeMB` | 单个时间胶囊大小上限，默认 50MB，触顶自动停止 |
| `xmuoj.timeCapsule.checkpointSeconds` | 写入完整文本检查点的间隔，默认 60 秒（10–600） |
| `xmuoj.timeCapsule.recordCursor` | 是否录制光标与选区，默认开启 |
| `xmuoj.timeCapsule.videoFps` | 导出 WebM 的帧率，默认 30（10–60） |
| `xmuoj.timeCapsule.videoWidth` / `videoHeight` | 导出视频尺寸，默认 1280×720 |
| `xmuoj.autoMigrate` | 启动时自动迁移旧目录（默认开启，可回滚） |
| `xmuoj.rememberContestPasswords` | 用系统钥匙串记住实验密码（默认开启） |

## 本地工作区结构（v0.1.0 起）

```
{localWorkspaceRoot}/
  problems/
    PTA1.1-求2数的积/
      problem.md          # 题目描述
      .xmuoj.json         # 题目元数据（schema v2，含实验信息）
      main.cpp / Main.java / main.py / main.c
      samples/            # 样例输入输出
      testcases/          # 下载的测试数据
    JD004-集市算账/
  .xmuoj/
    index.json            # 身份 → 目录索引（可重建）
    migration.json        # 迁移清单（回滚依据）
    migration.log.jsonl   # 迁移进度日志
    backup-v1/            # 迁移前的旧版元数据备份
```

- 题目身份为 `<站点>::<题目 id>`，同一道题无论在公共题库还是实验中都收敛到同一个目录。
- 目录名保留中文标题；重名时追加 `-p<题目 id>` 区分。
- 目录名中的 `!`、`$`、反引号会替换为全角 `！`、`＄`、`｀`，避免 zsh 历史扩展导致 VS Code 的“运行/调试”按钮执行失败；已有目录可执行 `修复题目目录名`（目录内有文件正在编辑时会跳过，关闭后重试）。
- 旧布局 `contest-<id>/...` 与 `problemsets/...` 首次启动会自动迁移；无元数据、正在编辑或符号链接的目录会跳过，不删除任何非空目录。
- 迁移失败或想恢复旧布局时，执行 `回滚目录迁移`。

## 补充说明

- 插件已内置对自签名证书的支持，无需额外配置
- 提交时若当前语言不在题目支持列表内，插件会自动提示并阻止提交
- 实验密码默认写入系统钥匙串；退出登录或执行「忘记实验密码」可清除
- 断网启动时不会清除登录凭证，状态栏显示离线并可重试
- 时间胶囊只录当前题目文件，纯本地保存、不上传；删除前需确认
- 如果题目绑定失效，提交前会提示重新绑定
